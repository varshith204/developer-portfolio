# Billakanti Varshith — Developer Portfolio

A responsive personal portfolio built with semantic HTML, modern CSS, and vanilla JavaScript.

## Features

- Responsive navigation and accessible skip link
- Dark/light theme, stored locally
- Interactive project filtering
- Profile, skills, projects, education, certifications, and contact sections
- Contact form that opens the visitor's configured email client

## Run locally

Open `index.html` in a browser, or serve this directory with any static web server.
